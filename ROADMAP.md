# Roadmap

What could come next. None of it is promised; all of it is open to contributors. Comment on an issue or start a [discussion](https://github.com/nrzz/claude-chat-ferry/discussions) before a large change.

- Readers for GitHub Copilot Chat and Cline task folders (fixtures and a reader each; Cline's is the [good first issue #3](https://github.com/nrzz/claude-chat-ferry/issues/3)).
- Antigravity's artifacts (`task.md`, `implementation_plan.md`, `walkthrough.md`) as an appendix of an export.
- A `.cursor/rules` or `.agents/rules` entry that points Cursor's and Antigravity's agents at an exported chat without an `@` mention.
- Cursor's agent-transcripts folder (`~/.cursor/projects/<slug>/agent-transcripts`) as a second source for newer builds.
